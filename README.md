# Персональные top-10 рекомендации: Amazon Video Games

**Акопян Микаэла, группа 517**

Датасет: **Amazon Reviews 2018 — Video Games (5-core)**.
[Первоисточник](https://cseweb.ucsd.edu/~jmcauley/datasets/amazon_v2/).

Самостоятельные реализации: ItemKNN, iALS, SLIM, FM с брендом, категориями и train-признаками пользователя, ALS с рейтинговым целевым сигналом. Код обучения и предсказаний находится в `models/`, общий протокол ранжирования — в `evaluation.py`.

## Запуск

Проверено на Python 3.12, CPU. Из папки задания:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/download_data.py
```

Для независимой проверки математики: `python scripts/check_models.py`. Для автоматического выполнения в новом ядре: `python scripts/run_notebook.py`.

Откройте `experiments.ipynb` в Jupyter или VS Code, выберите созданное окружение и выполните ячейки сверху вниз. Установите Jupyter отдельно, если нужен его браузерный интерфейс. Ноутбук содержит выполненные ячейки, EDA, формулы, протокол, validation-поиск и финальное сравнение на test.

Исходные gzip-файлы занимают около 198 МиБ. Их не нужно распаковывать. Данные, окружение и кеши исключены из Git. SHA-256 скачанных файлов записывается в `data/download_manifest.json`.

Разбиение: train до 2016 года, validation — 2016 год, test — с 2017 года. Релевантность — оценка 4–5. Основная метрика — NDCG@10; дополнительная — Recall@10. Ранжируется полный каталог train с исключением известных пользователю товаров. Для скорости оценка проводится на фиксированной случайной когорте, выбранной по train; обучение использует весь train. Все пять методов и дополнительный baseline популярности оцениваются одинаково. Для пары user–item сохраняется первый отзыв: будущие повторы не удаляют раннюю историю.

Ограничения: ретроспективный отбор 5-core, отсутствие исторических версий метаданных, warm-start, один временной split и seed, небольшой поиск гиперпараметров. SLIM ограничивает возможные ненулевые коэффициенты соседями, выбранными только по train. Для test модели не переобучаются на validation; история исключений обновляется.

Источник: Jianmo Ni, Jiacheng Li, Julian McAuley. *Justifying recommendations using distantly-labeled reviews and fine-grained aspects*, EMNLP 2019.

## Полученные результаты

| Модель | Test NDCG@10 | Test Recall@10 |
|---|---:|---:|
| SLIM | 0.01630 | 0.02306 |
| CustomALS | 0.01420 | 0.02543 |
| iALS | 0.01375 | 0.02329 |
| ItemKNN | 0.01048 | 0.01546 |
| FM | 0.00825 | 0.01554 |
| Popularity | 0.00747 | 0.01454 |

Таблица пересчитана после перехода к первому отзыву пары. iALS и CustomALS сравниваются по одинаковой сетке факторов {16,32} и регуляризации {1,10}. FM включает признаки активности и средней оценки пользователя, вычисленные только по train. Контроль ID-only исключает все метапризнаки. Bootstrap-интервалы и выводы приведены в ноутбуке.

Историческая доступность брендов и категорий остаётся допущением: источник не содержит версий метаданных. Пользовательские признаки гарантированно не используют будущие отзывы.
